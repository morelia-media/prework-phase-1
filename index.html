Git is a version control software that we run on our computer

Github on the other hand is a remote web application that works with git to help us collaborate with others and share our work

ddfullstack.cloud is the bootcamp server that runs our code

We add and commit our code to git on our computer

We push our code on github so that we can collaborate with others

We deploy code from our computer to the bootcamp server so that others can see the code in action

Deploying the code to the bootcamp server is fundamentally different from committing and pushing our code. When we deploy our code it is running/doing something . When we commit and push we are managing or editing the code not using it
